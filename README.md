# TEAM1 오픈소스 소프트웨어 기초 과제
## 주제: 반려동물 사전
---
## 설명
 Github를 통해 반려동물 종에 대한 설명이 담긴 사전을 제작한다. 
 사전의 내용은 동물 종에 대한 기본적 설명과 사육 방법을 포함한다. 
 
## 규칙
1. 각자 본인 이름의 브랜치에서 작업 후, Pull Request 진행한다.
2. 혹시 모를 충돌을 막기 위해 Pull Request 규칙을 정한다.
- 같은 공간에서 협업하는 경우, 구두로 Pull Request 진행을 알린다.
- 원격으로 협업하는 경우, 카카오톡을 통해 Pull Request 진행을 알린다.
3. 아래 양식을 사용해 각자의 사전을 작성한다.
4. 역할은 다음과 같이 정한다.
| 이름 | 담당 동물 |
|---|------|
|김민규|미정|
|박성모|a|
|박지환|b|
|오송은|c|
|전재우|d|
|한윤지|e|
