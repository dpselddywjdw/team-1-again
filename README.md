## 설명
Github를 통해 반려동물 종에 대한 설명이 담긴 사전을 제작합니다. 반려동물과 함께하는 가구가 늘어남에 따라, 각 동물의 생리학적 특징과 올바른 양육 환경에 대해 정확한 정보를 아는 것이 중요해졌습니다. 협업 과정을 통해 다양한 반려동물의 특성과 올바른 사육 방법, 건강 관리 방법 및 주의 사항을 한눈에 찾아볼 수 있는 **종합 사전**을 완성합니다. 팀원이 각자 하나의 동물 종을 맡아 사전을 작성할 것입니다. 사전의 주요 수록 내용은 다음과 같습니다. 
- 동물별 기본 정보: 학명, 생김새, 수명, 사육 난이도 및 신체적 특징
- 사육 환경과 양육 가이드: 적정 온습도, 영양 관리, 위생 관리 방법 등
- 기타 유의 사항: 주요 질환과 예방 접종, 행동 언어, 건강 관리 방법 등

현대 사회에서 반려동물은 단순한 유희의 대상이나 유용한 동물을 넘어, 인간과 감정을 공유하고 서로 의지하는 가족 구성원으로 자리 잡았습니다. 1인 가구 증가와 인구 구조의 변화와 새로운 라이프스타일의 확산으로 반려동물을 양육하는 인구는 매년 늘고 있습니다. 과거 개와 고양이로 대표됐던 반려동물을 넘어 이제는 토끼, 햄스터, 기니피그 같은 소형 포유류부터 앵무새 등의 조류, 그리고 파충류와 양서류에 이르기까지 다양한 종이 우리 주변에서 살아가고 있습니다. 그러나 이러한 변화에도 불구하고 올바른 반려 문화와 사육 정보의 보급은 여전히 미흡해 반려인들에게 혼란을 야기합니다. 인터넷 공간에는 근거가 부족하거나 개인의 주관에 의존한 잘못된 사육 지식이 무분별하게 공유되고 있으며, 부족한 케어는 반려동물의 건강과 삶의 질에 큰 영향을 끼칩니다. 이러한 배경 속에서 본 프로젝트는 반려동물을 키우는 누구나 쉽게 참조할 수 있는 종합 반려동물 사전을 구축하고자 기획되었습니다. 
  
## 규칙
0. Repository 초대 수락 후, 각자 본인 이름의 브랜치를 생성합니다. 
1. 각자 본인 이름의 브랜치에서 작업 후, Pull Request 진행합니다.
2. 혹시 모를 충돌을 막기 위해 Pull Request 규칙을 정합니다.
- 같은 공간에서 협업하는 경우, 구두로 Pull Request 진행과 충돌 가능성을 알립니다.
- 원격으로 협업하는 경우, 카카오톡을 통해 Pull Request 진행과 충돌 가능성을 알립니다.
3. README 아래 양식을 사용해 각자의 사전을 작성합니다.
4. 잘못된 정보나 오탈자 발견시 Issue 등록 혹은 Pull Request를 통한 기여를 부탁합니다.  
5. 역할은 다음과 같이 정합니다.
