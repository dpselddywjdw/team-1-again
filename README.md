## 설명
 Github를 통해 반려동물 종에 대한 설명이 담긴 사전을 제작한다.  사전의 내용은 동물 종에 대한 기본적 설명과 사육 방법을 포함한다. 
 
## 규칙
1. 각자 본인 이름의 브랜치에서 작업 후, Pull Request 진행한다.
2. 혹시 모를 충돌을 막기 위해 Pull Request 규칙을 정한다.
- 같은 공간에서 협업하는 경우, 구두로 Pull Request 진행과 충돌 가능성을 알린다.
- 원격으로 협업하는 경우, 카카오톡을 통해 Pull Request 진행과 충돌 가능성을 알린다.
3. 아래 양식을 사용해 각자의 사전을 작성한다.
4. 역할은 다음과 같이 정한다.
  
| 이름 | 담당 동물 | 페이지 |
|---|---|---|

|박성모|너구리|[너구리 페이지](너구리.md)|
|박지환|앵무새|[앵무새 페이지](bird.md)|
